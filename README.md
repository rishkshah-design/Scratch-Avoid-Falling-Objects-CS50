# Avoid Falling Objects - CS50 Problem Set 0

A Scratch project for CS50's Problem Set 0.

## Project Description

This is a game where the player controls a character to avoid falling objects from the top of the screen.

## Files

- `project.sb3` - The Scratch project file

## How to Use

1. Download the `project.sb3` file
2. Go to [scratch.mit.edu](https://scratch.mit.edu)
3. Click "Create"
4. Go to File > Load from your computer
5. Select `project.sb3`
6. Play and enjoy!

## Controls

Use arrow keys or mouse to move and avoid the falling objects.
